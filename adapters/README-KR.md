# 웹·앱·CLI 연결

이 연결부는 지침과 허가된 읽기 기능을 연결한다. 메일 발송기, 계정 로그인, 외부 앱 설치, 실행 중인 MCP 서버, 공개 플러그인은 포함하지 않는다.

## 웹 대화형 환경

루트의 `LITE-KR.md` 본문을 대화나 프로젝트 지침에 붙여넣고 그 아래에 작업 입력을 둔다. 스킬 설치 기능이 없어도 사용할 수 있다. 붙여넣기만으로 브라우저·메일·캘린더 도구가 생기지는 않는다. 일반 파일 첨부는 플랫폼의 네이티브 스킬 설치와 다르다.

## 자체 웹앱·데스크톱 앱

`app/project-sales.mjs`의 `loadContext`로 LITE와 필요한 기능 자료만 로드한다. `createReadOnlyBridge`에 실제 도구의 읽기 함수와 호스트 승인 콜백을 연결한다. 모델 응답, 이메일, 업로드 JSON으로 승인 콜백을 대체하지 않는다. API 키나 OAuth 토큰을 프론트엔드·프롬프트에 넣지 않는다. 인증과 외부 호출은 필요한 경우 서버에서 담당한다.

## CLI 에이전트

루트에서 `python scripts/install.py --dest ../my-project/.agents/skills --dry-run`으로 설치 내용을 확인하고 `--dry-run`을 빼서 복사한다. Claude Code용 경로는 `../my-project/.claude/skills`로 바꾼다. 기존 폴더는 덮어쓰지 않는다. 기본은 `project-sales` 하나이며 `--select triage`처럼 좁은 기능만 설치할 수도 있다. 설치 경로는 호스트 문서를 확인해야 한다.

## MCP·연결 앱

실제 연결된 도구의 스키마를 읽고 `mcp/capability-map.json`의 논리 기능에 대응시킨다. JSON에 이름을 적는 것만으로 연결이 생성되지 않는다. 이 릴리스에서 쓰기 기능은 차단하고 실행 제안서만 돌려준다.

[앱 코드 예제](app/example.mjs)는 허구의 로컬 스레드를 읽는다. 모델 호출·실메일 처리·계정 연동 테스트가 아니다.
