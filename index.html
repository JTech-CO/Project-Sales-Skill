Before you start.시작하기 전에.

Do I need to install every skill?스킬을 전부 설치해야 하나요?

No. Start with the core project-sales router, or install only the specialist skills needed for a narrow role. Detailed references are read when useful, not loaded by default.아닙니다. 기본 project-sales 라우터 하나를 설치하거나, 좁은 역할에 필요한 선택 스킬만 설치합니다. 상세 참조 문서는 필요한 작업에서만 읽습니다.

Does it send messages or book meetings?메일 발송이나 미팅 예약도 실행하나요?

This version creates analysis, drafts, and proposals, with host-authorized reads when connected. It includes no sender, remote CRM writer, calendar writer, or scheduler. Actual execution needs a separate host integration.이 버전은 분석·초안·제안서를 만들고, 연결된 경우 호스트가 허가한 읽기 기능을 사용합니다. 발송기·원격 CRM 수정·일정 생성·스케줄러는 포함하지 않습니다. 실제 실행에는 별도의 호스트 연결이 필요합니다.

Will it work in my agent?사용 중인 에이전트에서 쓸 수 있나요?

LITE works as text guidance in a host that accepts instructions. Native installation depends on SKILL.md support and the host’s configuration. Available tools and permissions stay with the host; the package does not claim identical behavior across every model.지침을 받는 환경에서는 LITE를 텍스트로 사용할 수 있습니다. 네이티브 설치는 SKILL.md 지원 여부와 호스트 설정에 따라 달라집니다. 도구·권한은 호스트가 제공하며 모든 모델의 동일한 동작을 보장하지는 않습니다.
